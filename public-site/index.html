BioMat Lab — scientific intelligence platform

BioMat Lab records laboratory experiments, understands what each measured variable means, and compares results — between two runs of your own work, and against published literature. It is built to be topic-agnostic: a deep eutectic solvent (DES) extraction project and a protein purification project use the same engine with different variable definitions.

Everything on this page is synthetic example data. The working platform is private: project and experiment records are only visible after signing in, and this public page never reads them.

A. What the platform does

  • Project-scoped variables. Each project defines its own measured variables with a unit, a scientific role and, for derived values, a formula. No chemistry field is hard-coded.
  • Variable roles. A variable is a parameter (a condition you set), a result (an outcome you measure), a derived result (computed from other measurements), an identifier or a covariate. The AI proposes the role from the name, the unit and the project description; the researcher can change it.
  • Comparability check. Before two numbers are compared, the platform checks whether they mean the same thing: same result definition, same unit, same numerator and denominator, same material, same measurement method.
  • Literature extraction. Given a paper, the platform extracts parameters and results, keeps the source location of every value, and marks each value as extracted, verified or corrected.
  • CSV / JSON export. Records leave the platform in an open format.

Interpretation

Observed: the run that heated first and milled afterwards recovered more lignin (2.30 % vs 0.96 % of dry biomass).

Possible explanations: heating may dissolve lignin before mechanical treatment, exposing fresh surface; or milling for the whole period may shorten contact with the liquid phase.

Alternative explanations: run-to-run variation (no replicates were recorded); or a different local temperature at the sample despite the same set point.

Limits: two single runs, no replicate statistics, so no causal claim is made.

F. Scientific comparability

Two numbers are only compared after their definitions are compared. The platform returns one of four statuses:

  1. Directly comparable — same definition, unit, material and method.
  2. Comparable with caveats — same definition, but a caveat such as a single run.
  3. Not directly comparable — the numbers mean different things.
  4. Insufficient information — one side lacks the definition or the method.

Worked example: lignin yield vs lignin recovery

MetricDefinitionExample value
Lignin yieldrecovered lignin / dry biomass12.93 % (388 mg from 3 g)
Lignin recoveryrecovered lignin / lignin in the biomass58.8 % (388 mg from 660 mg)

Both come from the same 388 mg of lignin, yet they are not the same measurement. A comparison between a yield and a recovery is reported as not directly comparable, with the two definitions shown side by side, and the platform asks for a conversion to a common basis before any difference is calculated.
